# Oscar Daily Pull

Pull today's dashboard sleep screen and briefing EPUB from Oscar's daily feed.

- **On the reader:** Home → Plugins → *Oscar Daily Pull* lists today's files; tap to download. Dashboard → `/sleep.bmp`; briefing → `/briefing.epub`.
- **In the WebUI:** Settings → *Oscar Daily Pull* — set the feed base URL once, then pull either file or both.
- Set **Settings → Display → Sleep Screen → Custom** so the dashboard becomes the sleep screen.
